# 📊 Sales Data Analysis

## 📌 About the Project

This project is part of my learning journey in Data Analytics and Data Science.

The goal is to explore a sales dataset, identify patterns, analyze business performance, and extract insights that can support data-driven decision-making.

- Explore and understand the dataset

- Analyze revenue and product performance
- Practice data cleaning and exploratory data analysis (EDA)
- Communicate findings through visualizations
